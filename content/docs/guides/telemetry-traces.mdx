- `.swarm/telemetry.jsonl` for agent runs and cost events
- `.swarm/traces.jsonl` for span records
- `SWARM_OTEL_EXPORT=1` for optional OTel export

Opik cloud is **not implemented**. Local JSONL is the source of truth.
