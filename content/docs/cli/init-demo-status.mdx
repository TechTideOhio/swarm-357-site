| Command | Description |
|---------|-------------|
| `swarm init` | Create `.swarm/`, install config and souls |
| `swarm demo` | 60-second simulation without API keys |
| `swarm status` | Health dashboard; `--json` for machine output |
| `swarm status --config path` | Use alternate roster YAML |
